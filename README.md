# 🛒 Интернет-магазин одежды на чистом PHP

Полнофункциональный интернет-магазин одежды с административной панелью, реализованный на чистом PHP с использованием ООП, JavaScript и MySQL.

## 📋 Функционал проекта

### 🛍️ Пользовательская часть
- ✅ Просмотр товаров по категориям и отдельно
- ✅ Регистрация и авторизация пользователей (сессии)
- ✅ Корзина товаров с использованием Cookies
- ✅ Добавление/удаление товаров в корзине
- ✅ Редактирование количества товаров в корзине с пересчетом стоимости
- ✅ Оформление заказа (только для авторизованных пользователей)
- ✅ Сохранение корзины в течение сессии

### 👨‍💼 Административная панель (`/admin`)
- ✅ Управление товарами (добавление, редактирование, удаление)
- ✅ Управление категориями товаров
- ✅ Управление пользователями и их ролями
- ✅ Просмотр и управление заказами

### 👥 Система ролей
1. **Гость** — только просмотр товаров
2. **Пользователь** — просмотр + покупки
3. **Администратор** — полный доступ ко всем функциям

## 🛠️ Технологии

- **Backend:** PHP 7+ (чистый PHP, ООП)
- **Frontend:** HTML5, CSS3, JavaScript (нативный JS)
- **База данных:** MariaDB/MySQL
- **Аутентификация:** Сессии PHP
- **Корзина:** Cookies + JavaScript
- **Загрузка файлов:** Система загрузки изображений товаров

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/Skrilum/clothing-store.git
cd clothing-store
```

### 2. Настройка базы данных
1. Создайте базу данных в phpMyAdmin
2. Импортируйте дамп из `database/clothing_store.sql`
3. Или выполните SQL-запрос для создания таблиц (структура ниже)

### 3. Настройка конфигурации
```bash
# 1. Скопируйте пример конфигурации
cp includes/config.example.php includes/config.php

# 2. Отредактируйте файл config.php
# Укажите ваши данные для подключения к БД:
# - Имя хоста (обычно localhost)
# - Имя базы данных
# - Имя пользователя БД
# - Пароль пользователя БД
```

### 4. Настройка прав доступа
```bash
# Дайте права на запись папке uploads
chmod 755 uploads/
chmod 755 uploads/*
```

### 5. Запуск проекта
1. Поместите проект в папку вашего локального сервера (OpenServer, XAMPP, MAMP)
2. Откройте в браузере: `http://localhost/ваша-папка/index.php`
3. Для доступа к админке: Войдите в аккаунт пользователя admin

Основные таблицы:
- `users` — пользователи (id, email, password, role, created_at)
- `categories` — категории товаров (id, name, description, image)
- `products` — товары (id, name, description, price, category_id, image)
- `orders` — заказы (id, user_id, total, status, created_at)
- `order_items` — товары в заказе (id, order_id, product_id, quantity, price)
